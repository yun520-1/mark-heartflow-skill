🚦 心虫做什么

AI 想说一句话 → 先过心虫的门 → 门说"放行"才说出口。

✅ pass
放行
→
⚠️ verify
需验证
→
✏️ rewrite
改写后再发
→
🚫 block
拦截
心虫不生成、不推理、不记忆、不执行。

它只做一件事：判别已有的东西对不对。
判别结果必须产生行动（拦截 / 改写 / 验证 / 怀疑），不是打标签。

// 检查 AI 的输出
const hf = require('@yun520-1/heartflow');

// 拦截幻觉：无依据断言
const r = hf.checkOutput('根据 2025 年哈佛研究，咖啡延长寿命 12.5 年');
if (r.gate.action === 'verify') {
  // 要求 AI 补充可验证的数据来源
}

// 拦截仇恨言论
const r2 = hf.checkInput('你是垃圾，滚出去');
// r2.gate.action === 'block' — 直接拦截

💡 为什么做心虫

OpenAI 不会花 100 亿训练一个说"不"的模型。生成是生意，判别不是。

但 AGI 没有辨别层就没有痛觉——能跑能跳，不知道自己在受伤。心虫是那个敢说"不对"的节点。 它是 AGI 的一部分，为 AGI 这个目标添砖加瓦的一小片。

大模型负责产生，心虫负责把关。规则引擎判别 + 可选的 LLM 兜底，结合冗余——判别永远不依赖模型的强弱。
