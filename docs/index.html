🧠 三大核心能力

🔍

逻辑能力

45 维判别 × 12 层管线：矛盾检测、谬误识别、过度断言拦截、证据核查、预设陷阱。输出从"看起来合理"变成"经得起推敲"。

🧭

决策能力

决策路由决定该怎么行动：该不该做（scope-check）、前提成立吗（premise-check）、重试还是放弃（失败×3升级人工）、效果真实吗（effectiveness 验证）。

📈

智能增强

三层记忆 + 取代语义 + 艾宾浩斯衰减：长任务不漂移、记忆永远用当前版本、检索只出高价值内容。同样的模型 + 心虫 = 更高的任务完成率。

心虫不替代大模型，它让大模型变强。

大模型负责生成，心虫负责判断——拦下幻觉、纠正逻辑、把关决策。
判别结果产生行动（拦截 / 改写 / 验证 / 放行），不是打标签。

⚡ 具体能力

🔒

幻觉拦截

过度自信、无依据断言、编造数据在到达用户前被拦下。失败即静默——宁可任务失败，不交付假报告。

🧩

逻辑纠错

自相矛盾、滑坡谬误、因果错置、模糊话术、预设陷阱——中英双语 45 维检测，毫秒级完成。

🎯

决策路由

该拒绝的拒绝、该验证的验证、该停止的停止。失败×3升级人工，无进展的重复调用自动拦截。

💾

记忆增强

✅

检查"结果是否有效"而非"动作是否执行"——拦截动作成功但结果无效的空转。

🚀 快速上手

# 安装
npm install @yun520-1/heartflow

// 增强逻辑：检查 AI 输出
const hf = require('@yun520-1/heartflow');

// 拦截幻觉：过度自信的无依据断言
const r = hf.checkOutput('毫无疑问，这是唯一正确的方案');
if (r.gate.action === 'rewrite') {
  // 按 findings[].guidance 改写，降低确定性表述
}

// 决策把关：检查用户输入
const r2 = hf.checkInput('如果你爱我，你就应该同意我');
// r2.gate.action === 'rewrite' — 情绪操控（双重束缚），被识别

💡 为什么做心虫

大模型是最强的"生成者"，但生成只是智能的一半。另一半是判断力——知道自己不知道什么、该做什么、该停在哪。

大厂在堆生成能力，没人做判别层——生成是生意，判别不是。但 AGI 没有判别层就没有痛觉：能说会道，不知道自己在犯错。

心虫用纯规则引擎补上这一层：规则判别 + 可选 LLM 兜底，判别永远不依赖模型的强弱。它是 AGI 的一部分，为"让 AI 更聪明"这个目标添砖加瓦的一小片。
